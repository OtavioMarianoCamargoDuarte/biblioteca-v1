# 📚 Biblioteca V1

Sistema de gerenciamento de biblioteca desenvolvido em Python com foco em estudo de Programação Orientada a Objetos (POO), Git, GitHub, funções, modularização e organização de projetos.

## 🚀 Funcionalidades

Atualmente o sistema permite:

- ✅ Listar livros
- ✅ Buscar livros por título
- ✅ Cadastrar novos livros
- ✅ Remover livros
- ✅ Menu interativo no terminal

## 🛠️ Tecnologias Utilizadas

- Python 3
- Git
- GitHub
- Programação Orientada a Objetos (POO)

## ▶️ Como Executar

Clone o repositório:

```bash
git clone https://github.com/OtavioMarianoCamargoDuarte/biblioteca-v1.git
```

Entre na pasta:

```bash
cd biblioteca-v1
```

Execute o sistema:

```bash
python main.py
```
